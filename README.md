# Упрощённая монополия

Настольная игра для 2–4 игроков с графическим интерфейсом на PyQt5. Все клиенты подключаются к одной схеме Oracle: в базе хранятся комнаты, партии, ходы, владения, аукционы, чат, история и статистика.

## Состав проекта

- `app` — приложение и графический интерфейс;
- `database` — создание таблиц, справочников, типа и пакета `MONOPOLY`;
- `.env` — параметры подключения к Oracle;
- `requirements.txt` — зависимости Python.

## Что потребуется

- два компьютера в одной локальной сети;
- Windows 10/11;
- Python 3.12 x64 на обоих компьютерах;
- Oracle Database Free/XE на первом компьютере;
- доступ к TCP-порту Oracle (обычно `1521`) со второго компьютера.

Игра не требует отдельного веб-сервера. Первый компьютер одновременно запускает Oracle и обычный клиент игры, второй запускает только клиент и подключается к Oracle первого компьютера.

## 1. Подготовка Oracle на первом компьютере

Установите Oracle Database Free/XE и убедитесь, что база и Listener запущены. Для стандартной установки Oracle Database Free используется сервис `FREEPDB1` и порт `1521`.

Создайте отдельного пользователя игры. Откройте SQL*Plus или SQL Developer от имени администратора Oracle и выполните:

```sql
ALTER SESSION SET CONTAINER = FREEPDB1;

CREATE USER monopoly IDENTIFIED BY "123321"
  DEFAULT TABLESPACE USERS
  QUOTA UNLIMITED ON USERS;

GRANT CREATE SESSION, CREATE TABLE, CREATE PROCEDURE, CREATE TYPE
  TO monopoly;
```

Если пользователь `monopoly` уже существует, повторно создавать его не нужно. Можно использовать другой логин и пароль, но тогда одинаково измените `ORACLE_USER` и `ORACLE_PASSWORD` в `.env` на обоих компьютерах.

Проверьте Listener:

```powershell
lsnrctl status
```

В выводе должны присутствовать TCP-порт `1521` и сервис `FREEPDB1`. Oracle должен принимать подключения не только с `localhost`. Если Listener привязан только к `127.0.0.1`, укажите в его конфигурации имя компьютера или его адрес в локальной сети и перезапустите Listener.

Разрешите входящие подключения к Oracle в брандмауэре первого компьютера. PowerShell нужно открыть от имени администратора:

```powershell
New-NetFirewallRule -DisplayName "Oracle Monopoly TCP 1521" -Direction Inbound -Protocol TCP -LocalPort 1521 -Action Allow -Profile Private
```

Разрешайте порт только для доверенной частной сети. При запросе Windows отметьте текущую сеть как частную.

## 2. Установка проекта на обоих компьютерах

На каждом компьютере откройте PowerShell и выполните:

```powershell
git clone https://github.com/Po-lin-ka/Monopoly.git
cd Monopoly
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `python` не найдена, установите Python 3.12 x64 с сайта Python и при установке включите пункт `Add Python to PATH`.

## 3. Настройка `.env`

На первом компьютере оставьте локальное подключение:

```dotenv
ORACLE_USER=monopoly
ORACLE_PASSWORD=123321
ORACLE_DSN=localhost:1521/FREEPDB1
POLL_INTERVAL_MS=2000
```

Узнайте IPv4-адрес первого компьютера:

```powershell
ipconfig
```

Нужен адрес активного сетевого адаптера, например `192.168.1.25`. На втором компьютере в `.env` укажите этот адрес вместо `localhost`:

```dotenv
ORACLE_USER=monopoly
ORACLE_PASSWORD=123321
ORACLE_DSN=192.168.1.25:1521/FREEPDB1
POLL_INTERVAL_MS=2000
```

`ORACLE_USER`, `ORACLE_PASSWORD` и имя сервиса должны быть одинаковыми на обоих компьютерах. Различается только адрес: `localhost` на первом компьютере и его локальный IPv4-адрес на втором.

Перед продолжением проверьте со второго компьютера доступность Oracle:

```powershell
Test-NetConnection 192.168.1.25 -Port 1521
```

В результате должно быть `TcpTestSucceeded : True`. Если адрес компьютера изменился после перезагрузки роутера, снова выполните `ipconfig` и обновите `ORACLE_DSN` на втором компьютере.

## 4. Однократная установка базы

Только на первом компьютере, из корня проекта, выполните:

```powershell
.\.venv\Scripts\python.exe -m database.install
```

Ожидаемый результат:

```text
Схема установлена. Пакет MONOPOLY: VALID.
```

Установщик запускается один раз для пустой схемы. На втором компьютере эту команду выполнять нельзя: оба клиента используют уже созданные общие таблицы и пакет. Повторная установка поверх существующих объектов завершится ошибкой.

## 5. Запуск игры на двух компьютерах

На каждом компьютере из папки проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m app.main
```

Дальнейший порядок:

1. На каждом компьютере зарегистрируйте отдельный игровой аккаунт. Это аккаунты внутри игры, а не пользователи Oracle.
2. На первом компьютере войдите и создайте комнату минимум для двух игроков.
3. На втором компьютере войдите под другим аккаунтом, выберите появившуюся комнату и нажмите «Присоединиться».
4. Оба игрока нажимают «Я готов». После десятисекундного отсчёта партия начнётся.

Окно приложения можно запускать на первом компьютере только после запуска Oracle. Оба клиента должны оставаться подключёнными к одной сети и использовать одну схему Oracle.

## Если второй компьютер не видит игру

Проверяйте по порядку:

1. Оба компьютера подключены к одной сети, а в `.env` второго компьютера указан текущий IPv4-адрес первого.
2. `Test-NetConnection <IP-первого-компьютера> -Port 1521` возвращает `True`.
3. На первом компьютере запущены служба Oracle и Listener.
4. В Listener зарегистрирован сервис `FREEPDB1`.
5. В брандмауэре первого компьютера разрешён входящий TCP-порт `1521` для частной сети.
6. Логин, пароль и имя сервиса в `.env` совпадают на обоих компьютерах.
7. Команда `python -m database.install` была выполнена ровно один раз и завершилась сообщением `VALID`.

Если Oracle сообщает, что пользователь заблокирован, администратор может разблокировать его и назначить новый пароль:

```sql
ALTER SESSION SET CONTAINER = FREEPDB1;
ALTER USER monopoly IDENTIFIED BY "123321" ACCOUNT UNLOCK;
```

## Остановка

Закройте окно игры обычным способом. При кратком обрыве сети клиент попытается восстановить соединение и загрузить актуальное состояние партии. Длительное отключение участника обрабатывается правилами игры.
